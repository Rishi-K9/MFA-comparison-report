Multi-Factor Authentication (MFA) Comparison Report

Project Overview

This project explains Multi-Factor Authentication (MFA) and compares the three major authentication factors: knowledge, possession, and inherence.

Authentication Factors

Knowledge Factor

Something the user knows, such as a password, PIN, or passphrase.

Possession Factor

Something the user has, such as a mobile phone, security key, or smart card.

Inherence Factor

Something the user is, such as a fingerprint, face, or iris.

How MFA Improves Account Security

MFA improves account security by requiring two or more independent authentication factors. If one factor is compromised, the additional factor can help prevent unauthorized access.

Is OTP Alone MFA?

No. An OTP alone is not necessarily MFA. MFA requires two or more different authentication factors. For example, a password combined with an OTP can provide MFA.

Conclusion

Multi-Factor Authentication provides an additional layer of protection and helps reduce the risk of unauthorized account access.
